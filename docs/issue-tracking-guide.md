# Issue Tracking Evidence

`issue-tracker.csv` contains the seven tracked findings with IDs, locations, significance, resolution, and final status. It is suitable for importing/copying into the issue tracker used for the course (for example GitHub Issues/Projects, Jira, or another approved tracker).

For assignment evidence, capture the tracker showing SQ-1 through SQ-7 and their final Resolved/Closed status. Open at least one security issue in the tracker for a detail screenshot showing the problem, location, significance, planned correction, and resolution.

The CSV is documentation of the issue records; if the instructor requires evidence from an actual tracking system, create/import these records there and submit screenshots or a repository/project link. Do not represent the CSV alone as an external issue-tracking system if the course requires one.
